# Revit Export Manager - Releases & Installation
# מאגר קבצי התקנה - Revit Export Manager

<div dir="rtl" align="right">

ברוכים הבאים למאגר הרשמי של קובצי ההתקנה וההפצה עבור **Revit Export Manager**.

תוסף זה מאפשר יצוא מהיר, מדויק ומתקדם של גליונות ומבטים מתוך Autodesk Revit לפורמטי **PDF**, **DWG** ו-**DWF/DWFx**, כולל ניהול שמות קבצים חכם לפי פרמטרים, תמיכה מלאה בריבוי שפות (כולל הדפסה שקטה ב-PDF24 עבור עברית ו-RTL), בחירת גרסת AutoCAD, מיזוג סימבולים מקוננים לבלוקים, ושליטה מדויקת בהגדרות הדפסה ו-XREF.

---

### 📦 הורדת קובץ ההתקנה העדכני

- **[לחץ כאן להורדת קובץ ההתקנה: RevitExportPlugin_v1.0.4.exe](../../releases/latest/download/RevitExportPlugin_v1.0.4.exe)**
- **גרסה נוכחית:** `v1.0.4`
- **גרסאות Revit נתמכות:** `2023`, `2024`, `2025`, `2026`, `2027`.

---

### ✨ חידושים עיקריים בגרסה `v1.0.4`

- **שיפורי יצוא DWG מתקדמים:** בחירת גרסת קובץ AutoCAD (`R2018`, `R2013`, `R2010`, `R2007`), איחוד אוטומטי של סימבולים מקוננים לבלוקים נקיים (`Merge nested symbols into AutoCAD blocks`), והסרת רקע אטום מטקסטים ומידות.
- **הדפסת PDF שקטה ומדויקת:** תמיכה מלאה בייצוא שקט ברקע דרך **PDF24** ללא חלונות קופצים, זיהוי אוטומטי של גודל הגיליון ושמירה על קנה מידה מדויק (`1:1` / `100% Zoom`).
- **מערכת עדכונים משופרת:** בחירת מיקום שמירה לקובץ ההתקנה הכולל את מספר הגרסה בשם הקובץ.

---

### 🚀 הוראות התקנה

1. **סגור את תוכנת Revit** במידה והיא פתוחה.
2. הורד והפעל את קובץ ההתקנה `RevitExportPlugin_v1.0.4.exe`.
3. עקוב אחר הוראות אשף ההתקנה (ההתקנה פורסת אוטומטית את התוסף לתיקיות ה-Addins עבור גרסאות Revit המותקנות במחשבך).
4. פתח את Revit – בלשונית התוספים (**Add-Ins**) יופיע כפתור ההפעלה של **Export Manager**.
