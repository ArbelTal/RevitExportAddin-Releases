# Revit Export Manager - Releases & Installation
# מאגר קבצי התקנה - Revit Export Manager

<div dir="rtl" align="right">

ברוכים הבאים למאגר הרשמי של קובצי ההתקנה וההפצה עבור **Revit Export Manager**.

תוסף זה מאפשר יצוא מהיר, מדויק ומתקדם של גליונות ומבטים מתוך Autodesk Revit לפורמטי **PDF**, **DWG** ו-**DWF**, כולל ניהול שמות קבצים חכם לפי פרמטרים, תמיכה מלאה בריבוי שפות (כולל עברית), ושליטה מדויקת בהגדרות הדפסה ו-XREF.

---

### 📦 הורדת קובץ ההתקנה העדכני

- **[לחץ כאן להורדת קובץ ההתקנה: RevitExportPlugin_v1.0.2.exe](../../releases/latest/download/RevitExportPlugin_v1.0.2.exe)**
- **גרסה נוכחית:** `v1.0.2`
- **גרסאות Revit נתמכות:** `2023`, `2024`, `2025`, `2026`, `2027`.

---

### 🚀 הוראות התקנה

1. **סגור את תוכנת Revit** במידה והיא פתוחה.
2. הורד והפעל את קובץ ההתקנה `RevitExportPlugin_v1.0.2.exe`.
3. עקוב אחר הוראות אשף ההתקנה (ההתקנה פורסת אוטומטית את התוסף לתיקיות ה-Addins עבור גרסאות Revit המותקנות במחשבך).
4. פתח את Revit – בלשונית התוספים יופיע כפתור ההפעלה של **Export Manager**.
