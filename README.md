# Revit Export Manager - Releases & Installation
# מאגר קבצי התקנה - Revit Export Manager

<div dir="rtl" align="right">

ברוכים הבאים למאגר הרשמי של קובצי ההתקנה וההפצה עבור **Revit Export Manager**.

תוסף זה מאפשר יצוא מהיר, מדויק ומתקדם של גליונות ומבטים מתוך Autodesk Revit לפורמטי **PDF**, **DWG** ו-**DWF/DWFx**, כולל ניהול שמות קבצים חכם לפי פרמטרים, תמיכה מלאה בריבוי שפות (כולל הדפסה שקטה ב-PDF24 עבור עברית ו-RTL), בחירת גרסת AutoCAD, מיזוג סימבולים מקוננים לבלוקים, ושליטה מדויקת בהגדרות הדפסה ו-XREF.

---

### 📦 הורדת קובץ ההתקנה העדכני

- **[לחץ כאן להורדת קובץ ההתקנה: RevitExportPlugin_v1.0.10.exe](../../releases/latest/download/RevitExportPlugin_v1.0.10.exe)**
- **גרסה נוכחית:** `v1.0.10`
- **גרסאות Revit נתמכות:** `2023`, `2024`, `2025`, `2026`, `2027`.

---

### ✨ חידושים עיקריים בגרסה 1.0.10

- **שמירת מדפסת PDF לכל פרופיל בנפרד:** תוקן סדר הטעינה בעליית התוסף כך שהמדפסת שנבחרה לפרופיל (כגון PDF24 או Revit Internal PDF) נשמרת ונטענת איתו במדויק. כל שינוי בתיבת המדפסות נשמר אוטומטית ובזמן אמת לפרופיל הפעיל.
- **סידור אופטימלי של מסך הגדרות הפורמט (Format Tab):** חלוקה מאוזנת ל-3 עמודות קומפקטיות המבטיחה שכל אפשרויות היצוא יוצגו במלואן במסך ללא צורך בגלילה וללא אלמנטים שנחתכים.
- **סימון מהיר וגורף לשורות מרובות:** בלחיצה על תיבת סימון (Checkbox) בגיליון מתוך קבוצת גיליונות מסומנים, כל הגיליונות שנבחרו מסומנים/מבוטלים יחד באופן מיידי.
- **אבטחה ורישוי מתקדמים:** אימות רישוי ישיר, מהיר ומאובטח מול פונקציות ענן מוצפנות (Supabase RPC), חתימה דיגיטלית מאומתת (Authenticode SHA-256) לכל קובצי ההתקנה וה-DLLs.

---

### 🚀 הוראות התקנה

1. **סגור את תוכנת Revit** במידה והיא פתוחה.
2. הורד והפעל את קובץ ההתקנה `RevitExportPlugin_v1.0.10.exe`.
3. עקוב אחר הוראות אשף ההתקנה (ההתקנה פורסת אוטומטית את התוסף לתיקיות ה-Addins עבור גרסאות Revit המותקנות במחשבך).
4. פתח את Revit – בלשונית התוספים (**Add-Ins**) יופיע כפתור ההפעלה של **Export Manager**.
